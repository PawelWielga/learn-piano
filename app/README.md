# Learn Piano Web

Web-only Flutter application for the first MVP. The project is deliberately small: a landing screen and a microphone tester placeholder. Audio capture, MIDI import, pitch detection and training will be added in their corresponding issues.

## Prerequisites

- Flutter **3.47.7** (stable; Dart 3.13.5)
- Chrome for local web development

## Run

```sh
cd app
flutter pub get
flutter run -d chrome
```

## Validate and build

```sh
cd app
dart format --output=none --set-exit-if-changed .
flutter analyze
flutter test
flutter build web --release --base-href /learn-piano/
```

The build outputs `app/build/web`. The base href must match the GitHub Pages repository subpath. Don't commit generated `build/` files. The browser bootstrap script is generated by Flutter during the build.

This scaffold does **not** request microphone permission yet and does not upload audio or MIDI. No backend or authentication is needed.

> The initial scaffold was prepared without a local Flutter SDK. Run `flutter pub get` with the pinned version and commit the generated `pubspec.lock` before considering issue #1 fully complete. The GitHub Actions workflows validate the remaining steps.
